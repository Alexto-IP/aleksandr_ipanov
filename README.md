# Портфолио / резюме — Александр Ипанов

Одностраничное приложение-резюме на **React + TypeScript + Vite + Tailwind CSS**.

## Запуск

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173`.

## Сборка

```bash
npm run build
npm run preview
```
