# Портфолио / резюме — Александр Ипанов

Одностраничное приложение-резюме на **React + TypeScript + Vite + Tailwind CSS**.

## Запуск

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173`.

## Сборка

```bash
npm run build
npm run preview
```

## Доступ
Проект можно посмотреть по адрессу: https://alexto-ip.github.io/aleksandr_ipanov/

## Локализация (RU/EN)

Сайт двуязычный. Переключатель — в шапке (кнопки RU/EN).

Язык определяется в таком порядке:
1. Сохранённый выбор пользователя (`localStorage`), если он уже переключал язык вручную.
2. Иначе — по IP-региону через публичный сервис `ipapi.co` (без ключа API).
3. Если сеть недоступна/сервис не ответил — по языку браузера (`navigator.language`), затем по часовому поясу (`Intl.DateTimeFormat`).
4. По умолчанию — английский.

Весь двуязычный контент (имя, опыт, навыки, проекты, контакты, подписи интерфейса) лежит в одном файле:

```
src/data/content.ts
```

Внутри — объект `content` с ключами `ru` и `en`. Меняешь текст там — вёрстка сама подхватывает
изменения на обоих языках. Компоненты в `src/components/*` трогать не обязательно, если просто
нужно обновить контент.

Логика определения и хранения языка — в `src/i18n/LanguageContext.tsx`.
