# Портфолио / резюме — Александр Ипанов

Одностраничное приложение-резюме на **React + TypeScript + Vite + Tailwind CSS**.

## Запуск

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173`.

## Сборка

```bash
npm run build
npm run preview
```

## Как редактировать контент

Весь текстовый контент (имя, опыт, навыки, проекты, контакты) вынесен в один файл:

```
src/data/resume.ts
```

Меняешь данные там — вёрстка сама подхватывает изменения. Компоненты в `src/components/*`
трогать не обязательно, если просто нужно обновить резюме.

Не забудь заменить плейсхолдер ссылки на hh.ru в `contacts` на прямую ссылку на своё резюме.

## Деплой

Проект — статический сайт после `npm run build` (папка `dist/`). Можно задеплоить на
Vercel, Netlify, GitHub Pages или Cloudflare Pages без дополнительной конфигурации.
